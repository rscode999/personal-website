# Personal Website
**Skills and project showcase**

## Foreword

My previous React project, a website for the Geodata project team, was not used. The team got another website.

But the skills I learned did not go to waste...

Using the same React/Vite framework, I decided to create a website of my own. I used some of the components that I developed for the Geodata website, along with some new CSS features.

## Run Instructions
You need [Node.js](https://nodejs.org/en/download) to run this website.

Once Node.js is installed, download dependencies, then start localhost:
```
npm install
npm run dev
```
