# Personal Website
**Skills and project showcase**

This website is a React/Vite.js 8.3.0 web app.

## Foreword

At the end of my 3rd year in undergrad, I worked on a React project for the Geodata project team. I implemented 14 new pages, added CSS effects, and gave the website a unified style. When I returned to school the following year, I learned that the team decided not to use my website.

But the skills I learned did not go to waste...

Using the same React/Vite framework, I decided to create a website of my own. I used some of the components that I developed for the Geodata website, along with some new CSS features.

## Run Instructions
You need [Node.js](https://nodejs.org/en/download) (any version compatible with v24.15.0) to run this website. 

Once Node.js is installed, open a terminal in the project's root directory.  
Download dependencies:
```
npm install
```
Then run a development server:
```
npm run dev
```
NPM will print a URL starting with `http://localhost:`. Paste the URL into a web browser to view the website. 

To test the website's production look and feel:
```
npm run build
npm run preview
```
View the website by visiting the URL printed by NPM.

To deploy to GitHub Pages:
```
npm run build
npm run deploy
```
The website deploys to https://rscode999.github.io/personal-website/#/.
